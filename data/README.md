# Dataset Information: SMS Spam Collection

## Overview
This project uses the **SMS Spam Collection** dataset, an approved option from Section 8 of the assignment specification.
- **Source:** UCI Machine Learning Repository (Dataset ID: 228)
- **URL:** https://archive.ics.uci.edu/dataset/228/sms+spam+collection
- **Records:** 5,574 English SMS messages tagged as either `ham` (legitimate) or `spam`.
- **Target Column:** `label` (`ham` / `spam`)
- **Text Column:** `text` (message body)

## How to download and use the full dataset
1. Download the ZIP file from UCI Machine Learning Repository:
   https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip
2. Extract `SMSSpamCollection` (tab-delimited file).
3. Convert or save it as `dataset.csv` with two columns: `label` and `text`.
   - A starter `dataset.csv` is already provided in this directory for immediate testing and prototyping.
